# HISTORIAS DE USUARIO – UNIRESERVE

## HU-01 – Consultar espacios disponibles

**Como:** estudiante de la universidad.
**Quiero:** consultar los espacios disponibles de la universidad.
**Para:** conocer qué espacios puedo utilizar para realizar una reserva.

### Criterios de aceptación

* El sistema debe mostrar una lista de los espacios disponibles.
* Cada espacio debe mostrar su nombre.
* Debe mostrar el tipo de espacio.
* Debe mostrar la capacidad.
* Debe indicar si el espacio se encuentra disponible.

---

## HU-02 – Ver información de un espacio

**Como:** estudiante de la universidad.
**Quiero:** consultar la información detallada de un espacio.
**Para:** conocer sus características antes de realizar una reserva.

### Criterios de aceptación

* El usuario debe poder seleccionar un espacio de la lista.
* El sistema debe mostrar el nombre del espacio.
* Debe mostrar el tipo de espacio.
* Debe mostrar la capacidad.
* Debe mostrar la descripción del espacio.
* Debe indicar su disponibilidad.

---

## HU-03 – Realizar una reserva

**Como:** estudiante de la universidad.
**Quiero:** realizar una reserva de un espacio.
**Para:** utilizarlo en la fecha y hora que necesito.

### Criterios de aceptación

* El usuario debe poder seleccionar un espacio.
* Debe poder ingresar la información necesaria para realizar la reserva.
* El sistema debe registrar la reserva.
* El sistema debe informar al usuario si la reserva fue realizada correctamente.
* La reserva debe quedar almacenada en el sistema.

---

## HU-04 – Consultar mis reservas

**Como:** estudiante de la universidad.
**Quiero:** consultar las reservas que he realizado.
**Para:** conocer y verificar mis reservas activas.

### Criterios de aceptación

* El sistema debe mostrar las reservas realizadas por el usuario.
* Debe mostrar la información correspondiente a cada reserva.
* El usuario debe poder identificar el espacio reservado.
* Debe mostrar la información de la fecha y hora de la reserva.

---

## HU-05 – Cancelar una reserva

**Como:** estudiante de la universidad.
**Quiero:** cancelar una reserva que ya no necesito.
**Para:** liberar el espacio y evitar mantener una reserva innecesaria.

### Criterios de aceptación

* El usuario debe poder seleccionar una reserva realizada.
* El sistema debe permitir cancelar la reserva.
* El sistema debe eliminar o cancelar la reserva correctamente.
* El sistema debe informar al usuario que la cancelación fue realizada.

---

## HU-06 – Confirmar una reserva

**Como:** estudiante de la universidad.
**Quiero:** visualizar la confirmación de mi reserva.
**Para:** verificar que el proceso de reserva se realizó correctamente.

### Criterios de aceptación

* El sistema debe mostrar una confirmación después de realizar la reserva.
* La confirmación debe permitir identificar el espacio reservado.
* Debe mostrar la información correspondiente a la reserva.
* El usuario debe poder verificar que la reserva fue registrada correctamente.
